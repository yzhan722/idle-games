# 亲密长期线（AR-G2）

规则代码：`public/intimacy.js`（纯函数），单测：`tests/intimacy.test.mjs`。

## 原来怎么涨

亲密只看经验，没有每日上限。倍率在日常养成里相乘：小夜灯亮 ×1.25、贝壳发卡 ×1.2、星梦花环 ×1.15、点香 ×1.1、听雨 ×1.05、围炉 ×1.04～1.08；LV.8 后自然拿到发卡和花环，常见倍率约 ×1.38。

## 现在怎么算

- **LV.8 以前照旧**：需求 40 起每级 ×1.3，第 1～2 天到 LV.8。（打工掉落那条路原来升级后 ×1.35，统一成 ×1.3，只会更快。）
- **LV.8 起按「相处的日子」**：
  - 每个自然日有 200 全额计入；没来的日子份额攒着，最多 7 天（1400），隔几天再来不会落后。
  - 份额用完后，互动按 10% 计入，一天最多再 40。
  - 打工掉落和讨伐首领的 45 只走这 40，不占陪伴的 200；班次经验、金币不变。
  - 日期按本地时间。时钟往回拨不补也不扣；退超过一天（例如年份曾经调错）就从现在的日子重新数，第二天照常补。
  - 界面不显示今天还剩多少，用完不提示；飘字里的数字等于真正计入的，没计入时只显示动作名。
- **LV.20 纪念日后**：不再升级、不再计入，经验条填满，所有互动照常。

天数由 `tests/intimacy.test.mjs` 的模拟核对：轻陪伴约 129 天、普通 90 天、怎么刷都不低于 75 天、一周只来一天（待久一点）不超过 100 天。「每天约 140 / 200」是按上表推的玩法假设，没有真人数据。

## 老存档

- 没有 `bond` 字段：LV.8 以下原样；LV.8 以上经验按原来的百分比换算到新需求，等级不掉（超过 20 的也不降）。
- LV.9～20 没发过的奖励一次补齐，只出一条提示（「手账补上 N 页」）。
- `bond = { v, pace{day,left,tail,carry}, claimed{等级:日期}, call, seen }`，缺字段或脏数据都有默认值，领过的不会重发。
