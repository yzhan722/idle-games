# 《世界历史疆域演化沙盒 (World History Evolution Atlas)》全局 PRD (v1.0)

## 1. 项目定位与核心设计哲学
- **项目名称**：World History Evolution Atlas（世界历史疆域演化沙盒）
- **技术栈**：纯前端 Web 标准架构（HTML5 + SVG 矢量地图 + CSS3 时代滤镜 + 原生 ES6 模块化 JS），零后端依赖，双击或任意静态服务即可丝滑运行。
- **核心设计哲学**：
  - **写死真实历史逻辑（Deterministic History）**：抛弃传统沙盒游戏复杂的随机概率状态机与生硬惩罚机制，直接以人类真实历史时间轴（`公元前 3000 年 -> 公元 2026 年`）为唯一驱动轴。
  - **挂机看海 + 轻交互百科**：支持全自动倍速播放人类五千年帝国兴替，同时提供时间轴自由拖拽、时代书签秒跳、点击版图查阅帝国鼎盛数据、当世列强版图排行榜以及丝绸之路/大航海动态航线演进。

## 3. 核心功能模块规范

### 3.1 全球历史宏观地理区块 (`src/data/regions_geo.js`)
将全球划分为 42 个核心历史地理区块（涵盖北美、中美、安第斯、欧洲各大历史区、北非、埃及、黎凡特、两河、波斯、小亚细亚、钦察草原、河中、印度河、恒河、德干、漠北、满洲、中原、关中、巴蜀、江南、岭南、西域、青藏、朝鲜、日本、东南亚、大洋洲等），每个区块包含：
- `id`：唯一英文标识符（如 `"north_china"`, `"jiangnan"`, `"egypt"`）
- `name`：中文历史地理名称
- `continent`：所属大洲分组
- `path`：SVG 多边形矢量路径
- `cx`, `cy`：标签渲染基准坐标

### 3.2 历史关键帧快照引擎 (`src/data/timeline_keyframes.js` & `TimelineEngine.js`)
每个关键帧定义如下结构：
```javascript
{
  year: 1337,
  era: "中世纪晚期大转折",
  theme: "era-medieval", // 触发对应时代视觉滤镜
  toast: "1337年：英法百年战争爆发；大元步入末年即将迎红巾军起义；马穆鲁克雄踞中东。",
  routes: ["silk_road", "indian_ocean"], // 激活对应动态贸易航线
  owners: {
    "north_china": "大元帝国",
    "jiangnan": "大元帝国",
    "egypt": "马穆鲁克苏丹国",
    "gaul": "法兰西王国",
    "britain": "英格兰王国"
    // ...仅需声明发生变更或统治中的纯粹主权国家实体，引擎自动按时间顺序累加快照
  }
}
```

### 3.3 四大交互体验闭环
1. **全景地图平移缩放与版图聚合**：
   - 支持鼠标左键拖拽平移地图、滚轮以鼠标为中心缩放（`0.8x ~ 4.0x`），以及右上角【一键复位视野】。
   - 当某帝国统治多个区块时，自动计算其统治区块的质心坐标，渲染带国徽色块的**大号帝国名牌**，小区块显示精简地域名。
2. **左侧实时【当世列强疆域榜 (Top Powers Leaderboard)】**：
   - 随年份流逝实时统计当前年份统治区块数与估算面积排名前 6 的帝国，显示动态进度条，点击榜单任意帝国可直接高亮其全球版图并打开百科卡。
3. **右侧【帝国鼎盛百科抽屉 (Empire Inspector)】**：
   - 点击地图任意区块或左侧榜单，展示该地区当前统治帝国的：国号、首都、政体类型、鼎盛陆地面积、核心历史评述，以及该地理区块的历代更替履历（Chronicle History）。
4. **底部时间轴控制器与顶部时代书签**：
   - 支持 `播放/暂停`、`1x / 5x / 20x / 50x` 倍速切换、全年代滑块自由拖拽，以及 10 个核心历史节点一键书签跳转。

## 4. Antigravity 后续演进任务路线图 (Next Milestones for AI Agent)
基础工程已包含完整可运行的 MVP 闭环。AI Agent 接手后的全局升级任务分为 3 个阶段：
- **Task 1（地图轮廓高精度化）**：在不破坏现有 42 个历史区块 `id` 映射的前提下，引入真实世界海岸线细分多边形路径（或接入 TopoJSON/GeoJSON 转换脚本），让大陆轮廓达到出版级历史地图集精度。
- **Task 2（历史关键帧加密至 100+ 节点）**：将 `src/data/timeline_keyframes.js` 从现有的 36 个节点加密至 100+ 个节点，精细还原春秋战国、楚汉、三国、五胡十六国、安史之乱、宋辽金夏、元末起义（朱元璋/陈友谅）、日本战国、三十年战争、拿破仑战争、1836-1936 维多利亚时代列强殖民、一战二战与冷战解体的逐年疆域变化。
- **Task 3（战役闪光与历史奇观标记）**：在特定年份于地图对应坐标渲染动态历史事件标记（如赤壁之战、君士坦丁堡陷落、哥伦布首航、第一次工业革命蒸汽机点亮），并在最后运行 `python tools/verify_project.py` 完成 100% 校验。
