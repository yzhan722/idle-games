# 给反重力 (Google Antigravity) 的全局启动指令包

## 使用说明
1. 将本压缩包解压到本地文件夹（例如 `world-history-atlas`），用 **Google Antigravity** 打开该文件夹。
2. **先直接双击 `index.html`**（或用本地 Live Server 打开），你会看到我已经为你写好的包含 **42 个全球历史区块、42 个帝国百科、36 个历史关键帧、列强排行榜、地图缩放拖拽与音效合成** 的完整可运行基础版。
3. 将客户端的模型挡位设为 **Medium**，直接复制下方【第一阶段全局任务指令】发送给 Antigravity 即可让它开始全自动扩充与精修。

---
