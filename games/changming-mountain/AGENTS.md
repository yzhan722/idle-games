# 《长明山》（暂名）开发规则

原创修仙放置新作。立项草案：`docs/xianxia-remake-plan.md`（仓库根目录下）。目标编号前缀 `XN`。

## 隔离规则（权利基线，不可放松）

- 禁止读取、复制、引用 `games/xianxia` 的任何文件；派子代理时必须写明这一条。
- 不以任何现有游戏或小说为蓝本逐项对照；名称、角色、境界、文案、数值、美术全部自己写、自己推导。
- 每加一个素材文件，先在 `ASSETS_LICENSE.md` 登记来源和可商用依据；`npm run guard` 会检查。
- 只用可商用许可的依赖；`npm run guard` 会检查。运行时零依赖。
- 页面不引用任何外部网址（字体、脚本、模型都自带或不用）。

## 美术规则（2026-11-25 用户要求，不可放松）

- 角色、道具、场景、界面装饰一律用生图或可商用的现成素材，**不许用 Canvas / SVG / CSS 画图形当美术**。代码只做光照、粒子、排版。
- 画风：青绿山水工笔，石青石绿、金线勾勒；素材按日光下的颜色画，夜色与灯光由 `src/ui/lightmap.ts` 乘上去。
- AI 生成的图要在 `ASSETS_LICENSE.md` 写明工具、日期、提示词文件；商店页如实披露 AI 内容。
- 现有成品都由 `C:\Project\_work\changming-art\tools\build_assets.py` 从原图生成；改图改脚本，别手改成品。

## 界面规则（2026-11-25 用户要求，不可放松）

- 休闲放置，少让玩家读字：图标优先，一张卡片一两句话，细节收在「说明」里。
- 正文 17px 起，任何字不小于 14px；说明只在玩家点开时出现。

## 内容上限（加一样必须先删一样，并由用户同意）

四种资源、七重境界、九层山台、12 名弟子、九条灯誓、约 40 种灯具；界面最多四页。

## 工程

- `src/core` 是不碰界面的纯逻辑，游戏、离线结算、模拟器共用；`src/ui` 只负责显示和输入。
- 单文件不超过 800 行。不用 emoji。
- 改数值后跑 `npm run simulate`；收尾跑 `npm run verify`。
- 没有用户要求，不提交、不推送、不部署。
