## 做了什么

- `index.html` 不再预加载 5 张面板舞台图（约 1.5 MB）；没打开的面板、弹窗里的图改成看得到才下载。
- 面板模块按需加载（`modules/app/lazy_panel.js`）：功能、挑战、帮助、萌灵、图鉴、商店、背包、排行榜、社交。打开时显示「正在打开…」，失败给「重试」（换地址），再失败、或旧页面遇到新模块时给「刷新」（先存档再刷新；断网时只给「重试」）。首屏之后空闲逐个预取，省流量模式不预取。
- 社交页签不再在启动时往隐藏面板里画 NPC（省 3 张立绘、5 枚图标）。
- 图标地址统一带 `?v=`：HTML / CSS 里原来不带，和 JS 画的同一枚各下一份。
- Google Fonts 样式不阻塞渲染。
- `app.js` / `type_zh.js` 首次不再带时间戳，能用上预加载和离线缓存；原来每开一次页面，Service Worker 里就多存一份。
- modulepreload 把 import 的多层瀑布摊平（请求数不变）。

## Service Worker 与离线

- 预缓存 128 + 22 项，原始 3.7 MB（首访时页面刚下过，`no-cache` 条件请求只回 304，不重复下正文）。清单由 `scripts/build-precache.mjs` 生成，`sw-selfcheck` 核对与文件、与模块图一致。
- **模块进预缓存**：首屏模块全部进（缺一个就不装，继续用旧版）；按需面板模块也进（缺了不影响安装）。理由：压缩后合计不到 600 KB，换来断网也能进每个面板。
- **图**：首屏 23 张与立绘兜底图进预缓存；立绘、其余图标、舞台图看到才下并留在本机，断网时没看过的立绘退回爪印徽记。
- HTML / JS / CSS / 数据联网优先（条件请求），断网或服务器 5xx 用本版缓存；图本机缓存优先，别的版本号来要图先联网。**换图必须升版本号。**
- 预缓存是装这一版时的整套快照，之后不改；Pages 没有 404.html，缺的文件会回「200 + 首页」，Service Worker 见到就当没拿到，不存。
- 升级：新 Service Worker 整套装好、接手时才删旧版本的缓存；页面自己不删缓存、不自动刷新（0.7.62 起）。

## 还能做、没做的

- `modules/systems/pve_tower.js`（400 KB）和 `systems/collection/`（约 450 KB）是读档、产出、结算都要用的规则，首屏必须有；要拆得先把「纯规则」和「面板用的数据与文案」分开。
- 101 个 JS 请求没有合并：仓库没有打包工具，本轮不加依赖。上打包（例如发布时用 esbuild 合成 3～4 个文件）可以把请求降到个位数，JS 传输还能再少三成左右（估）。
- `styles.css` 378 KB（传输 47 KB）没拆。

锁定：`scripts/first-screen-selfcheck.mjs` 的预算（JS ≤ 1760 KB / 105 个，图 ≤ 520 KB / 28 张，传输合计 ≤ 1000 KB，请求 ≤ 135）。
