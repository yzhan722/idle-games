# 游戏设计原则

## 核心设计理念

### 1. 放置类游戏特性
- **自动进行**: 采集和战斗自动进行，无需持续操作
- **离线收益**: 玩家离线时也能获得进度（待实现）
- **循环玩法**: 采集→加工→装备→战斗的循环
- **长期目标**: 等级提升、装备强化、技能解锁

### 2. 多职业系统
- **6个职业**: 每个职业有独特的采集和加工技能
- **职业平衡**: 每个职业都有价值，互相依赖
- **自由切换**: 玩家可以随时切换职业
- **共享进度**: 战斗等级和金币全局共享

### 3. 经济系统
- **资源流动**: 采集→加工→交易→消费
- **玩家交易**: 通过交易行进行物品交易
- **价格机制**: 供需关系影响价格
- **金币消耗**: 强化、修理、交易手续费

### 装备生产系统
**核心设计：三大职业分工制作装备**

#### 伐木工（木制装备专家）
- 制作所有木制装备：胸甲、护腿、靴子、手套
- 制作伐木斧（战斗武器）
- **强化能力**：可以强化所有木制装备和武器
- 技能节点：
  - 6级解锁：木制装备制作
  - 30级解锁：木制装备强化

#### 铁匠（金属装备大师）
- 制作所有金属装备：铁制、钢制胸甲、护腿、靴子、手套
- 制作锻造锤和盾牌（战斗武器）
- **强化能力**：可以强化所有金属装备和武器
- 技能节点：
  - 10级解锁：金属装备锻造
  - 30级解锁：金属装备强化
  - 40级解锁：钢制装备锻造

#### 裁缝（布甲皮甲专家）
- 制作所有布制装备：长袍、裤子、鞋子、手套
- 制作所有皮制装备：胸甲、护腿、靴子、手套
- 制作裁缝剪（战斗武器）
- **强化能力**：可以强化所有布制和皮制装备
- 技能节点：
  - 5级解锁：裁缝剪和基础布甲制作
  - 8级解锁：布制装备制作
  - 12级解锁：皮制装备制作
  - 30级解锁：布甲皮甲强化

#### 其他职业
- 农夫、厨师、炼金术师：只能制作自己的战斗武器
- 所有职业的防具都由伐木工、铁匠、裁缝制作
- 装备强化需要找对应的职业：
  - 木制装备 → 伐木工
  - 金属装备 → 铁匠
  - 布制/皮制装备 → 裁缝

### 战斗职业系统
**核心特色：生活职业的工具就是战斗武器！**

每个生活职业对应一个战斗职业，使用工作工具作为武器战斗：

**狂战士（伐木工）** 🪓
- 武器：伐木斧
- 主属性：力量
- 角色：DPS（输出）
- 特点：高额伤害，持续输出，狂暴状态
- 技能：劈砍、顺劈斩、狂暴、嗜血、斩杀

**铁壁（铁匠）** 🛡️
- 武器：锻造锤 + 盾牌
- 主属性：体质
- 角色：坦克
- 特点：高防御，高生命，保护队友
- 技能：锤击、盾牌猛击、坚固、钢铁之躯、嘲讽

**自然使者（农夫）** 🌾
- 武器：锄头 + 镰刀
- 主属性：智慧
- 角色：辅助
- 特点：增益队友，削弱敌人，持续恢复
- 技能：自然打击、自然祝福、虚弱诅咒、丰收、生长

**圣厨（厨师）** 🍳
- 武器：平底锅 + 锅铲
- 主属性：智慧
- 角色：治疗
- 特点：强大治疗，移除负面，保护队友
- 技能：平底锅猛击、快速料理、盛宴、滋养、复苏料理

**影刃（裁缝）** ✂️
- 武器：裁缝剪刀
- 主属性：敏捷
- 角色：刺客
- 特点：高爆发，高暴击，快速连击
- 技能：剪切、连续剪击、潜行、精准切割、刺杀

**药剂师（炼金术师）** ⚗️
- 武器：炼金瓶 + 法杖
- 主属性：智力
- 角色：法师
- 特点：魔法伤害，范围攻击，元素效果
- 技能：魔法箭、投掷药剂、元素转化、炼金精通、终极药剂

### 职业平衡原则
- 每个职业的收益应该相近
- 高级资源需要更多时间但收益更高
- 制作物品的价值应高于原材料
- 跨职业合作有额外收益

## 战斗系统

### 战斗机制
- **读条制**: 玩家和敌人都有3秒读条时间
- **自动战斗**: 读条完成自动攻击
- **连续战斗**: 胜利后自动开始下一场
- **死亡复活**: 死亡后60秒复活，怪物状态保持

### 战斗平衡
```typescript
// 伤害计算
baseDamage = ATK - floor(DEF / 2)
actualDamage = baseDamage * (0.8 ~ 1.2) // 随机波动

// 胜率计算
levelDiff >= 5:  95% (轻松)
levelDiff >= 3:  85% (有利)
levelDiff >= 1:  70% (有利)
levelDiff == 0:  50% (均势)
levelDiff >= -2: 35% (困难)
levelDiff >= -4: 20% (困难)
levelDiff < -4:  10% (危险)
```

### 怪物设计
- **3个地图**: 森林、矿山、沼泽
- **等级递增**: 森林(1-10)、矿山(11-20)、沼泽(21-30)
- **BOSS怪物**: 每个地图有一个BOSS
- **掉落物品**: 金币、经验、稀有材料

## 进度系统

### 等级系统
```typescript
// 经验计算（指数增长）
xpForLevel(level) = 100 * (level - 1) ^ 1.5

// 双等级系统
- 职业等级: 影响采集和制作
- 战斗等级: 影响战斗能力
```

### 技能树
- **解锁条件**: 等级要求 + 前置技能
- **技能效果**: 提升效率、解锁新功能
- **重置机制**: 可以重置技能点（消耗金币）
