# 开发工作流程

## 开发环境设置

### 前端开发
```bash
cd worklife/frontend
npm install
npm run dev
```
访问: http://localhost:5173

### 后端开发
```bash
cd worklife/backend
npm install
npm run dev
```
访问: http://localhost:3001

### 同时运行前后端
```bash
cd worklife
npm run dev
```

## 开发流程

### 1. 新功能开发
1. 查看 `TODO.md` 确认任务
2. 在 `TODO.md` 中标记任务为进行中
3. 创建功能分支（可选）
4. 实现功能
5. 运行诊断检查
6. 测试功能
7. 更新文档
8. 标记任务为完成

### 2. Bug修复
1. 重现问题
2. 定位问题代码
3. 修复问题
4. 验证修复
5. 添加防御性代码（如需要）
6. 更新相关文档

### 3. 代码优化
1. 识别优化点
2. 运行性能分析（如需要）
3. 实施优化
4. 验证优化效果
5. 确保功能完整性
6. 记录优化内容

## 代码检查

### TypeScript诊断
使用 Kiro 的 `getDiagnostics` 工具检查代码：
```typescript
// 检查单个文件
getDiagnostics(["path/to/file.ts"])

// 检查多个文件
getDiagnostics([
  "backend/src/index.ts",
  "frontend/src/components/Component.tsx"
])
```

### 常见问题修复
- **未使用的变量**: 使用下划线前缀 `_variable`
- **未使用的导入**: 删除导入语句
- **类型错误**: 添加正确的类型注解
- **空值检查**: 使用可选链 `?.` 和空值合并 `??`

## 测试策略

### 手动测试清单
- [ ] 功能是否按预期工作
- [ ] 边界情况是否处理
- [ ] 错误情况是否有提示
- [ ] UI是否响应式
- [ ] 性能是否可接受
- [ ] 是否有TypeScript错误

### 测试场景
1. **采集系统**: 测试所有职业的采集功能
2. **战斗系统**: 测试战斗、死亡、复活流程
3. **制作系统**: 测试材料检查、批量制作
4. **交易系统**: 测试挂单、购买、取消
5. **装备系统**: 测试装备、卸下、属性计算

## 文档维护

### 必须更新的文档
- `README.md`: 项目说明和使用指南
- `TODO.md`: 任务状态和进度
- `API_REFERENCE.md`: API接口文档
- `DATABASE_DESIGN.md`: 数据库设计

### 可选文档
- `ARCHITECTURE.md`: 架构设计
- `DEPLOYMENT_GUIDE.md`: 部署指南

## 常见任务

### 添加新职业
1. 更新 `shared/enhanced_content_pack_chinese.json`
2. 添加采集资源数据
3. 添加制作配方数据
4. 更新前端职业配置
5. 添加职业图标和图片
6. 测试所有功能

### 添加新怪物
1. 在 `monstersByMap` 中添加怪物数据
2. 添加怪物图片（可选）
3. 配置掉落物品
4. 测试战斗平衡性

### 添加新物品
1. 在游戏内容包中添加物品定义
2. 更新 `getItemInfo` 映射
3. 更新 `getItemIcon` 映射
4. 添加物品图片（可选）
5. 测试物品获取和使用

### 优化性能
1. 使用浏览器开发工具分析性能
2. 识别性能瓶颈
3. 优化渲染逻辑
4. 减少不必要的状态更新
5. 使用 React DevTools 检查重渲染
6. 验证优化效果

## 部署流程

### 开发环境
- 自动重载
- 详细错误信息
- 开发工具可用

### 生产环境
1. 构建前端: `cd frontend && npm run build`
2. 构建后端: `cd backend && npm run build`
3. 配置环境变量
4. 启动服务
5. 验证功能
6. 监控日志

## 故障排查

### 前端问题
1. 检查浏览器控制台错误
2. 检查网络请求
3. 检查 React DevTools
4. 检查状态更新
5. 清除缓存重试

### 后端问题
1. 检查服务器日志
2. 检查数据库连接
3. 检查API响应
4. 验证请求参数
5. 检查环境变量

### 常见错误
- **CORS错误**: 检查后端CORS配置
- **401错误**: 检查token是否有效
- **500错误**: 检查后端日志
- **状态不更新**: 检查状态更新逻辑
- **样式不生效**: 检查CSS选择器优先级

## 最佳实践

### 开发时
- ✅ 频繁保存和测试
- ✅ 使用TypeScript严格模式
- ✅ 及时处理警告
- ✅ 保持代码整洁
- ✅ 编写有意义的提交信息
- ✅ **只在必要时创建文档文件**（如果不是开发依赖，不要创建）

### 避免
- ❌ **不要创建总结性、记录性的 Markdown 文件**（如 SUMMARY.md, CHANGES.md 等）
- ❌ **不要创建工作日志或进度报告文件**（使用 TODO.md 记录任务状态）
- ❌ 不要直接修改生产数据库
- ❌ 不要提交敏感信息
- ❌ 不要忽略TypeScript错误
- ❌ 不要跳过测试
- ❌ 不要留下调试代码
