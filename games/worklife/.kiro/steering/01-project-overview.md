# WorkLife 项目概览

## 项目简介
WorkLife（异世界打工生活）是一个多职业放置类RPG游戏，玩家可以选择6种职业进行采集、加工、战斗和交易。

## 技术栈
- **前端**: React 18 + TypeScript + Vite
- **后端**: Fastify + TypeScript
- **数据库**: PostgreSQL（可选，默认内存存储）
- **样式**: 原生CSS

## 核心功能
1. **6个职业系统**: 伐木工、铁匠、农夫、厨师、裁缝、炼金术师
2. **采集系统**: 每个职业有独特的采集活动
3. **加工系统**: 将原材料加工成成品
4. **战斗系统**: 读条制战斗，支持连续战斗和复活机制
5. **交易系统**: 玩家间物品交易
6. **装备系统**: 装备穿戴、强化、耐久度
7. **技能树系统**: 职业技能解锁

## 开发命令
```bash
# 后端
cd backend && npm run dev     # 启动 :3001

# 前端  
cd frontend && npm run dev    # 启动 :5173
```
