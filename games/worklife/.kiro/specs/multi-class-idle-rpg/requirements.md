# 需求文档 - WorkLife多职业放置RPG

## 介绍

WorkLife是一个基于Web的多职业放置类RPG游戏，支持伐木、采矿、战斗、制作等多种玩法。本文档描述了已实现的核心功能需求和未来扩展计划。

**当前状态**: ✅ 核心功能已完成（版本1.0.0）  
**技术栈**: React 18 + TypeScript + Node.js + Fastify 5 + PostgreSQL  
**部署方式**: Ngrok公网访问 + 本地开发环境

## 术语表

- **游戏系统**: 基于Fastify 5构建的WorkLife游戏引擎
- **玩家**: 拥有活跃游戏账户的用户
- **角色**: 玩家的游戏内化身，具有职业和属性
- **职业**: 6个可用职业之一（伐木工、矿工、农夫、厨师、裁缝、炼金术师）
- **生活技能**: 产生资源的非战斗活动（采集、加工、制作）
- **战斗系统**: 关卡刷怪的战斗机制
- **交易行**: 多人物品交换市场
- **聊天系统**: 实时通信（世界、职业、私聊频道）
- **组队系统**: 合作战斗组队功能
- **资源**: 游戏物品，包括材料、装备、消耗品
- **等级**: 物品和内容的品质等级（1-7级）
- **内容包**: 游戏数据配置（JSON格式）
- **背包系统**: 物品存储和管理

## 已实现需求

### 需求1：多职业系统 ✅

**用户故事：** 作为玩家，我希望体验6个不同的职业，每个职业都有独特的技能和资源链。

#### 验收标准

1. ✅ 游戏系统应当支持6个职业：伐木工、矿工、农夫、厨师、裁缝、炼金术师
2. ✅ 当伐木工执行活动时，游戏系统应当支持砍树（木材1-7级）、加工（木板）、制作（弓箭、木制装备）
3. ✅ 当矿工执行活动时，游戏系统应当支持挖矿（矿石1-7级）、精炼（金属锭）、制作（金属装备、工具）
4. ✅ 当农夫执行活动时，游戏系统应当支持种植（作物）、钓鱼、畜牧（动物产品）
5. ✅ 当厨师执行活动时，游戏系统应当支持食材加工、食物制作（战斗增益、饱腹效果）
6. ✅ 当裁缝执行活动时，游戏系统应当支持加工（羊毛转毛线）、装备制作（布甲、皮甲）
7. ✅ 当炼金术师执行活动时，游戏系统应当支持制药（药水）、法杖制作、水晶分解

### 需求2：生活技能和资源生产 ✅

**用户故事：** 作为玩家，我希望执行资源生产链，创造有价值的物品。

#### 验收标准

1. ✅ 当玩家执行生活技能活动时，游戏系统应当支持多层级生产链
2. ✅ 当资源被生产时，游戏系统应当更新背包系统，包含适当的等级分类
3. ✅ 当执行更高等级活动时，游戏系统应当要求适当的技能等级
4. ✅ 当玩家制作物品时，游戏系统应当从背包中消耗材料并添加产品
5. ✅ 游戏系统应当支持离线进度系统处理所有活动

5. ✅ 游戏系统应当支持按物品类型、等级、价格范围搜索和筛选
6. ✅ 游戏系统应当应用交易费用以维持经济平衡
