## 图片规格建议

- 角色立绘: 400x600px (PNG, 透明背景)
- 怪物图片: 200x200px (PNG, 透明背景)  
- 树木图片: 200x200px (PNG, 透明背景)
- 制作物品: 120x120px (PNG, 透明背景)
- 物品图标: 64x64px (PNG, 透明背景)
- Logo: 48x48px (PNG)
