## 图片要求
- 格式: PNG (带透明背景)
- 推荐尺寸: 128x128 到 256x256 像素
- 风格: 像素艺术或卡通风格，保持统一
- 建议资源网站:
  - [itch.io](https://itch.io/game-assets/free/tag-monsters/tag-pixel-art)
  - [CraftPix](https://craftpix.net/freebies/)
  - [OpenGameArt](https://opengameart.org/)

## 使用说明
1. 将图片文件放入此文件夹
2. 确保文件名与上述列表完全匹配
3. 刷新游戏页面即可看到图片
4. 如果图片加载失败，会自动显示emoji图标作为后备
