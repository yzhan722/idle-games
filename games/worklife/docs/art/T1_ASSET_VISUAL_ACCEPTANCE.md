## Visual acceptance (manual QA)

`PRODUCTION` in the lanes above is **file presence** (`PRODUCTION_PRESENT`): a WebP/PNG that meets `masterMinPx`.

`PRODUCTION_ACCEPTED` is a separate visual judgment. It is not a `contract.ts` status.

**Source** tells where the file came from. `drop-01` is external commercial art (`worklife-production-drop-01.zip`, unmodified). `generated` is an in-repo AI candidate made on 2026-09-02 to keep the pipeline moving while external Drop #2 is pending; chroma-key background removed, no upscale, no pixel edits beyond matting. Generated files are **candidates**: external art production may replace any of them at the same canonical path with no code change.

Checked: transparency, silhouette, crop, hierarchy, desktop 1440×900, mobile 390×844. No upscale. One contract-threshold change (`monsters/forest_boss` 1536 → 1024, owner instruction — see its row); every other threshold is unchanged.

P1 was started on 2026-09-03 by explicit instruction ("整体评估，有需要就执行"). P0 reached 19/19 on 2026-09-06 when the owner asked for the missing art to be generated in-repo and the Forest Boss master threshold was lowered to the generator's native 1024px.

Chroma-key note: the matte formula is `min(r, b) - g > 80 AND min(r, b) > 170` (both channels must be high *and* bright). The earlier `(r+b)/2 - g` form keys out saturated pure reds and would have hollowed the HP heart; the brightness floor was added on 2026-09-06 so deep violets (the `nav-magic` orb) are not punched out — blended edge pixels are still removed by the erosion pass, so masters matted before the change are unaffected. `--depink` is a separate opt-in pass for masters where the generator bled magenta into thin *opaque* parts of the subject (shrimp legs, the staff's glow halo): flagged pixels keep their dominant hue and only the other channel is pulled down, so it is never run on assets with intentional purples.

Gap listing: `python scripts/art-gaps.py [max-skill-level] [--monsters] [--gather]` walks the content pack (every action ≤ N yields / consumes, every monster rare and `drops[]` entry) and prints the `folder/id` keys that have no `.webp` / `.png` under `frontend/src/assets/t1/`, using the same folder routing as `itemFolderFor`. `--gather` reads the card tables in `NewGameInterface.tsx` and lists gather actions ≤ N whose `trees/<cardId>` scene is missing (those rows fall back to the output item's icon). It exits non-zero while any item is missing, so it is the checklist for the next sweep rather than a guess from the UI.

Batch matting: `python scripts/art-matte-batch.py <ids.txt> [--erode N] [--depink] [--only id,…]` mattes every `gen-item-<id>.png` master in the assets folder into the right `frontend/src/assets/t1/<folder>/` (same prefix routing as `itemFolderFor`) and finishes with the contact-sheet residue audit. Before matting, check the corners of each master: the model occasionally answers a blue or warm subject with a hot-pink or dimmed background (`(239, 5, 140)`, `(188, 0, 136)`) that the key `min(r,b)-g > 80 AND min(r,b) > 170` will not remove — regenerate those rather than loosening the key.

Ground-shadow rule (learned on `monsters/poison_frog`): when the model paints a shadow on the key itself it is the same hue but darker — `(160, 0, 140)` — and survives the brightness floor as an opaque blob under the subject. `python scripts/art-residue-mask.py <asset.webp>` shows it; `art-matte.py --deep-key` lowers the floor to 90 for that master only. Never use it on a subject with intentional purple. `python scripts/art-bgcheck.py <master.png …>` is the corner check described above.

Thin-subject rule (learned on `trees/linen`): erosion removes anything narrower than 2 × erode px, so sparse stems, wires or whiskers vanish and leave their tips floating. Prompt such subjects as one compact mass ("no thin isolated stems against the background") rather than lowering the erosion below 3 px, which lets the magenta fringe through.

Nav-icon UI states: selected / unselected / hover come from `.tab-btn` CSS; T1 primary tabs are never locked, so disabled is CSS-only (`opacity`). No asset carries a frame.
