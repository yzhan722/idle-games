# 银河奶牛放置（Milky Way Idle）调研与复刻差距（2026-09-03）

目标：把 WorkLife 做成"银河奶牛式"的多技能放置 RPG，UI 结构对齐，美术保持我们自己的厚涂风格并争取做得更好。梅尔沃放置（Melvor Idle）是银河奶牛的直接前身，两者在"技能列表 + 动作列表 + 队列 + 战斗自动化"上同构，本文以银河奶牛为准。

调研来源：官方 Wiki（Skills / Efficiency / Action Speed / Woodcutting / Rare Find / Food Slots / Abilities / Combat Style）、Steam 商店与补丁说明、玩家攻略（pcucgame、TapTap 安利、巴哈姆特讨论）。

## 1. 银河奶牛的核心循环（我们要复刻的东西）

| 系统 | 银河奶牛的做法 | 为什么重要 |
|---|---|---|
| 行动队列 | 排多个动作（可设次数或无限），前一个结束自动接下一个；建议最后一项排无限采集防空转；可调顺序、可插队 | 这是整款游戏的"计划感"来源，也是离线收益的载体 |
| 技能页 = 动作列表 | 每个技能一页，按等级排列的动作行：需求等级、时长、经验、产出、稀有掉落；未解锁的行也显示 | 玩家一眼看到"下一个等级买到什么" |
| 效率（Efficiency） | `保证次数 = 1 + floor(eff/100)`，余数为概率；来源：等级高出需求 +1%/级、装备、茶、社区 buff；不占时间、不作用于强化 | 让"练过头"也有回报，装备/消耗品有明确数值意义 |
| 动作速度 | `时间 = 基础 / (1 + 速度 + 工具速度)`，加成相加 | 工具链（斧头/锤子…）的存在理由 |
| 稀有发现 | 乘法加成，而非加法 | 稀有物的来源可控 |
| 战斗 | 全自动；食物槽/饮品槽按"缺血/缺蓝阈值"自动使用；技能按条件触发；同一怪连打；每 3 分钟怪物狂暴 +10%（Boss 10 分钟） | 战斗也能挂机，玩家的决策在"配置"而不是"点击" |
| 战斗经验分配 | 30% 给武器决定的主技能，70% 由护符决定或平均分给耐力/智力/攻击/防御 | 多条战斗技能线的养成感 |
| 离线 | 10 小时以上离线收益，回来看"这段时间做了什么" | 放置游戏的第一留存点 |
| UI | 左侧技能栏（图标 · 名称 · 等级 · 经验条，采集/生产/战斗分组，进行中的行高亮），中间是当前技能的动作列表，顶部当前动作+队列，右侧背包/装备 | 信息架构一致，没有"页面切换感" |
| 经济 | 玩家市场、公会、组队、聊天 | 长线，非本轮范围 |

玩家评价里反复出现的缺点：UI 过密（小字、层叠子菜单）、市场被老玩家定价、付费摩擦。这些正是我们可以做得更好的地方：**同样的信息架构，更松的排版和更好的美术**。

## 4. 我们做得比银河奶牛好的地方（保持）

- 每一行动作/配方都有插画或道具图，不是 32px 小图标堆叠。
- 难度标签与 Boss 提示来自确定性模拟（"预计剩 55% 生命 · 约 27 秒"），银河奶牛要靠第三方模拟器。
- 第一章有明确的教学目标条，银河奶牛新手期是"自己看 Wiki"。
- 离线报告分组（做了什么 / 收获 / 经验 / 状态），不是一段日志。

## 4.5 补充调研（2026-09-03 第二轮，官方 Wiki Abilities / Combat 页）

战斗子技能与经验分配（原文确认）：

- 七条战斗技能：耐力（每级 +10 HP）、智力（每级 +10 MP）、攻击（命中、攻速、施法速度）、防御（闪避、护甲、抗性）、近战 / 远程 / 魔法（对应伤害）。
- 经验：30% 给武器决定的主技能；护符决定的 70% "专注"技能；无护符时 70% 平均分给耐力 / 智力 / 攻击 / 防御 / 主技能（各 14%，主技能合计 44%）。
- 战斗等级 = `0.1 × (耐力 + 智力 + 攻击 + 防御 + max(近战, 远程, 魔法)) + 0.5 × max(攻击, 防御, 近战, 远程, 魔法)`。
- 命中 = `acc^1.4 / (acc^1.4 + eva^1.4)`；护甲减伤 = `100 / (100 + 护甲 − 穿透)`；攻速 = `基础 / (1 + 攻速加成)`。
- 狂暴：现版本每 60 秒 +10% 命中与伤害，最多 10 层（旧版 3 分钟）。

技能书（Abilities）：

- 56 本技能书，按等级分 5 档（1 / 20 / 40 / 50 / 60），全部来自怪物掉落或市场；重复读书给技能经验（1 级书 50 XP，其余 500 XP）。
- 技能槽由智力等级决定：1（<20）→ 2（20–49）→ 3（50–89）→ 4（90+），外加 1 个特殊技能槽。
- 触发条件：HP/MP 阈值（自己或队友）、增益/减益存在与否、敌人数量或状态、冷却就绪。技能自左向右按优先级自动释放。
- 1 级书示例：戳刺 / 划伤 / 敲击（15s 冷却，10 + 60% 主伤害）、小治疗（15s，回 20 + 30% 魔法伤害）。

梅尔沃放置（Melvor Idle）的差异：技能页附带"熟练度（Mastery）"二层成长；战斗是区域 / 地牢（多波 + 最终 Boss）/ 杀戮任务（Slayer）；有祈祷、Township 城镇；银行分页管理；没有玩家市场（单机经济）。银河奶牛在此基础上加了多人：市场、公会、组队、社区 buff、房屋。我们的方向以银河奶牛为准，梅尔沃只借"地牢多波"和"熟练度"作为后续可选项。
