## 做了什么

1. **面板按需加载**：12 个进阶面板用 `components/lazyPanel.tsx`（`React.lazy` + `Suspense`），打开时才下载，有「加载中」占位。登录页和主界面两个大块也换成同一套。
2. **失败重试**（`utils/lazyImport.ts`，纯逻辑有单测）：失败后隔 0.6、1.8 秒各试一次；有的浏览器会记住一次失败的动态 import，所以重试换成带 `?retry=` 的地址；样式没下来会先补样式。都不行显示「重试 / 刷新页面」。
3. **新版本发布**：旧块在服务器上已经没有时，取一次首页，入口文件名变了：登录页和主界面整页刷新，五分钟内只自动刷一次（记在 `history.state`，不占本地存储）；已经在游戏里时不自动刷，面板上提示「游戏更新了」由玩家点。`nginx.conf` 里首页每次都向服务器确认，`/assets/`（文件名带散列）缓存一年，`public/` 里同名的图标只缓存一天，`/api/` 不缓存。
   - 面板与主界面共用的模块单独成块 `game-shared`（`vite.config.ts`）：主界面换地址重试之后，面板不会再去拿原地址的主界面。`scripts/first-screen.mjs` 发现面板块引用主界面块会报错。
4. **图按最大显示尺寸重采样**（`scripts/art-resize.py`）：

## 加新图

1. 原图放进备份目录的 `t1/<类别>/`。
2. `python scripts/art-resize.py <备份>/t1 frontend/src/assets/t1`，再加 `--small` 输出到 `frontend/src/assets/t1_small`。只想处理几张就建一个只放这几张的目录当输入。
3. `scripts/art-size.test.ts` 会查：发布边长下限、图标 ≤ 60 KB、小图 ≤ 40 KB、整套 ≤ 40 MB、小图齐全。
