## 战斗

- 难度标签改为确定性模拟：`frontend/src/gameplay/fightPreview.ts` 与后端 `hp_combat` 逐事件同构，`scripts/fight-preview-parity.test.ts` 用 4 只怪 × 6 套装 × 有无重劈 = 48 场在真后端回放，胜负/双方剩余 HP 逐一相等。卡片与弹窗显示 `预计剩 X% 生命 · 约 N 秒`、`你每刀 / 它每击`。
- Boss：≤66% 预告"蓄力举盾"；重劈把 Boss 打过 60% 时同一刀震碎盾（不再因冷却被惩罚）；未穿甲时弹窗用数字说明（每拳 8 → 4）；预测会输的战斗需点两次确认；卡片显示"已击败 ×N"。
- 反馈：重劈就绪脉冲 + 音效 + 文案；伤害飘字与受击抖动接到服务端 HP 差值；阶段/重劈/掉落日志高亮；去掉恒为 1 的"第 N 场"；胜利面板先亮 1.5s 再弹构筑选择。
- 构筑选择：两条路线按"穿木甲 + 按时重劈打管家"给出每刀/每拳与预计剩余 HP。

## 界面

- 弹窗主按钮 sticky（桌面 900 高与手机 844 高都在折叠线以上），弹窗主图 220 → 168 / 128。
- 顶部活动栏与 toast 不再重叠（toast 移到底部）。
- 白杨卡与采集弹窗显示本步目标缺口（`原木 3/6`）；制作卡片直接写"材料齐了 / 缺 X"；切换活动有提示。
- 角色页：空槽有可装备物品时脉冲；选择器"点一件即可装备"+ 每件"装备"标签；数值变化闪 `+5`；第一章只显示主手/上衣。
- 移动端：头部三行 → 一行（152px → 65px）；工作页单棵树横排满宽。
- 生涯菜单：远期系统（声望/赏金/转生）在第一章标"第二章"禁用；商店不再卖第一章产出链（原木/木板）与无用的 HP/MP 药水；每日任务按玩家阶段过滤（不再给 250 金的玩家"消费 2000"）；章末目标按钮变为"领工钱 N"并直接打开成就；登录页加一句世界观。

## 验证

- 单测：后端 51/51，前端+脚本 78/78（含两条新的前后端同构测试）。
- `npm run build --workspace frontend` 通过。
- Playwright 9 个用例全绿（`t1-loop` 更新为断言真实防御 11；`vertical-slice` 在单件制作后改用 `waitIdle`，`stopActivity` 容忍活动自然结束——这两处以前依赖幽灵进度的存在）。
