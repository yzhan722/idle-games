# 云屿小集 · Cloud Isle Market

> **1.5D 浮空微缩生态岛 · 桌面底部常驻休闲挂机经营游戏 (Godot 4.3)**

![Cloud Isle Market Preview](preview_engine_1920x360.png)

## 游戏简介

**《云屿小集（Cloud Isle Market）》** 是一款常驻在 Windows 桌面底部（`1920 × 300` 无边框透明穿透视口）的 **1.5D 斜向微缩景观（Diorama）休闲挂机种田与集市经营游戏**。

玩家无需繁忙点击土地，岛上的 **6 位动物伙伴** 会全自动完成 **翻土播种、汲水灌溉、采收鲜果、垂钓锦鲤、木工修缮、石臼捣糕与炼金熬饮** 的完整生态闭环，吸引森林与云海旅人跨过木吊桥与荷花池栈桥前来集市采购。

---

## 核心特色

- **1.5D 微缩浮空三岛景观**：
  - **晨风主岛（Cloudbrook Meadow）**：半木结构风车农舍（带袅袅炊烟）、晨风红苹果树、石子小径、荷花池与跨池木栈桥、双层可视化货架集市摊位。
  - **荧光森谷左岛（Glowwood Mystic Forest）**：树洞草药炼金屋、苔原林地、发光荧光菇良田。
  - **珊瑚晴滩右岛（Coral Sunlit Beach）**：椰壳彩灯冷饮吧、暖金干沙滩与海浪浅滩、热带凤梨良田。
- **100% 动物自主农耕与双段料理工坊**：
  - **月兔农夫**：自动播种、采收与石臼锤打 **桂花糯米糕** / **焦糖苹果草莓派**。
  - **荷叶水獭**：往返荷花池汲水灌溉三岛良田，闲暇时品尝茶点或打盹小憩。
  - **木工柴犬**：巡视修缮工坊与摇落红苹果。
  - **垂钓小企鹅**：在荷花池西侧木栈桥头垂钓黄金锦鲤。
  - **森谷小狐狸 & 海岛大嘴鸟**：采集荧光菇与黄金凤梨，熬制 **星露荧光甘露饮** 与 **海岛凤梨椰奶冻**。
- **精细地形导航与步态物理细节**：
  - **多段桥头路径规划与水面碰撞约束**：角色严格沿左岛吊桥弧线、荷花池木栈桥、右岛吊桥与干沙滩（避开海浪区域）行走，过桥时触发木桥动态微沉与桥桩水波涟漪。
  - **细腻步态动画**：正弦步幅微跃、触地挤压拉伸（Squash & Stretch）、左右摇摆倾角、平顺转身插值与脚跟草屑尘埃粒子。
- **原生 Win32 桌面穿透与丝滑拖拽**：
  - 基于 `SetWindowRgn` + `window_set_mouse_passthrough` 实现天空区域点击穿透，按住浮空岛或底部胡桃木黄铜 HUD 任意位置即可 **60 FPS 丝滑拖动窗口**。

## 运行方式

1. 需要 **Godot Engine 4.3+**（Windows 64-bit）。
2. 直接在命令行运行：
   ```powershell
   Godot_v4.3-stable_win64.exe --path .
   ```
3. 或使用 Godot 4.3 编辑器打开 `project.godot` 并按 `F5` 启动。
